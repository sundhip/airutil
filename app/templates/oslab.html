💡 What is cgroup v2?
Control Groups (cgroups v2) provide unified kernel resource accounting and partitioning. The Linux Completely Fair Scheduler (CFS) enforces CPU limits via cpu.max (quota per period). For this container, 50,000 µs runtime per 100,000 µs period caps execution at exactly 0.5 CPU cores. If a process consumes more, the kernel deschedules it and increments nr_throttled.

💡 What are Linux Namespaces?
Namespaces partition global kernel resources. CLONE_NEWPID makes Gunicorn master appear as PID 1 inside the container, preventing visibility of host processes. CLONE_NEWNET isolates network interfaces and loopback. CLONE_NEWUTS provides an independent hostname.

💡 OverlayFS vs. Dedicated Volumes
Docker root filesystems combine immutable read-only image layers (lowerdir) with an ephemeral writeable layer (upperdir). Because Airutil enforces read_only: true, rootfs writes trigger kernel EROFS. Persistent storage (/vault_storage) mounts directly from the host filesystem, providing durable I/O without union overhead.

CFS Throttling Stress Test

10-Second Probe

Spawns a busy-loop calculation thread inside this container. Watch CPU Throttled counter jump in Card 1 as the Linux kernel caps execution to 50% CPU!

💡 What causes CFS Throttling?
When the busy-loop thread runs, it demands 100% of a core. But Docker's cpus: '0.50' allows only 50ms of execution per 100ms window. The Linux kernel forcibly suspends the thread for the remaining 50ms, protecting neighboring processes on the host.

Fault Tolerance Demo

Zero Downtime

Simulate a sudden container crash on your host terminal. Nginx automatically fails over all traffic to the surviving replica:

docker stop airutil_app1

Refresh this page: the active replica instantly switches to app2. Re-start it whenever you like:

docker start airutil_app1
💡 How does Nginx detect replica failure?
Nginx uses max_fails=3 fail_timeout=10s in its upstream block. When TCP connection fails or timeouts occur, Nginx transparently passes the client's request to the remaining backend container with zero user-visible error.
